# Assignment 4 - Simple and Multiple Linear Regression

Dataset used:
- Insurance Charges dataset (direct CSV URL)
- Source: https://raw.githubusercontent.com/stedy/Machine-Learning-with-R-datasets/master/insurance.csv

## Files
- `insurance_regression_assignment4.ipynb`: Main notebook submission file.
- `requirements.txt`: Python packages needed to run the notebook.

## How to run
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Open `insurance_regression_assignment4.ipynb` and run all cells.

The notebook includes:
- Simple Linear Regression
- Multiple Linear Regression
- MAE, RMSE, and R^2 comparisons
- Required visualizations and final analysis
